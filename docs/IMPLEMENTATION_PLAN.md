## В работе

### P0. Деньги
Проблемы, найденные аудитом:
1. Двойное нажатие «Оплатить» создаёт две оплаты: нет идемпотентности.
2. `paidAmount` считается как «прочитал → прибавил → записал»: две параллельные оплаты одного счёта теряют одну из сумм.
3. Статус счёта считается в пяти местах API и в демо; в трёх местах скидка не учитывается, поэтому счёт со скидкой не становится «Оплачен».
4. Суммы считаются в `Number` с допуском `+ 0.001`.
5. У оплаты нет автора.

Решение:
- `packages/shared/src/money`: суммы в копейках (целые), `invoiceStatus(total, discount, paid)` — единственное правило статуса.
- `apps/api/src/domains/invoice-ledger.ts`: `applyToInvoice(tx, invoiceId, deltaKopecks)` блокирует строку счёта (`SELECT … FOR UPDATE`), пересчитывает сумму и статус. Через него идут оплата, оплата на приёме, возврат, депозит и рассрочка.
- `Payment.idempotencyKey` (уникален в клинике) и `Payment.createdById`. Повторный запрос с тем же ключом возвращает ту же оплату.
- Интеграционный тест: две параллельные оплаты, повтор с тем же ключом, скидка, возврат.

Критерий готовности: тесты зелёные; на сервере повтор с тем же ключом не создаёт вторую оплату.

### P0. 2FA при входе
`login` не спрашивает код, если 2FA включена. Решение: при `totpEnabled` вход без верного `code` возвращает 401 `{ requires2fa: true }`, экран входа показывает поле кода.

### P0. Резервные копии
На сервере была только ручная копия. Решение: `/etc/cron.d/dentasmart-backup`, ежедневный `pg_dump -Fc` в `/root/dentasmart-backups`, хранить 14 дней; проверка восстановления в отдельную базу.

### P1. Расписание
- Проверка пересечений идёт до создания записи и вне транзакции: два администратора могут записать двух пациентов в одно кресло. Решение: проверка и создание в одной транзакции с блокировкой по креслу и врачу (`pg_advisory_xact_lock`), плюс ограничение-исключение в Postgres на пересечение интервалов одного кресла.
- Статус визита меняется произвольно (`updateStatus` принимает любую строку). Решение: таблица допустимых переходов в `packages/shared`, проверка на сервере.
